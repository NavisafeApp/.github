# Assets do perfil

## Marca NaviSafe

- `logo.png`: logo utilizada em [navisafe.com.br](https://navisafe.com.br/logo.png), convertida para PNG sem alteração visual.
- `banner.svg`: composição para o GitHub com a logo original incorporada, sem fontes ou imagens externas.
- Paleta extraída dos estilos públicos do site: `#FF6B00` (principal), `#FF8638` (laranja claro), `#E55F00` (laranja escuro) e `#0A0D14` (fundo).
- A base branca atrás da logo segue a apresentação do cabeçalho do site. A composição do banner não é um novo logo.
